# Robert: AI-Powered Learning Platform 🇳🇬

Robert is an educational platform built in Nigeria for students
and teachers. It combines an AI tutor, exam practice, and live
multiplayer quizzes.

**Live site:** https://pelumismartal.hyp.app

## What it does
- **AI tutor:** answers study questions, explains topics, and
  summarises notes
- **Exam practice:** JAMB, WAEC and NECO style practice questions
  and mock exams, with scores and rankings
- **Robert PLAY:** single-player and multiplayer games and
  live quiz competitions
- **Live rooms for teachers:** hosts create rooms, add questions,
  and upload images, diagrams and voice notes
- **Hack the Vault:** a security-themed learning game
- **Accounts and chat history:** users can return to earlier
  conversations
- **Paid features:** larger live rooms and Host Pass, paid
  through Paystack

## Tech
- Backend: Node.js
- Frontend: HTML, CSS and JavaScript
- Login protection: Cloudflare Turnstile
- Extras: text-to-speech, web search, email
- Hosting: Render, with automated deployments
